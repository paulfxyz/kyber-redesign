# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, assume good intent, and make room for people who are new — including people contributing translations in their own language for the first time.

Report unacceptable behaviour to **hello@paulfleury.com**. Reports are handled confidentially.
